ADIL RAHMAN — DIGITAL MARKETING PORTFOLIO
========================================

FILES
- index.html: Website structure and content
- style.css: Dark blue theme, layout, responsive styles
- script.js: Mobile menu, current year, copy-email action, reveal animation

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser such as Chrome.

BEFORE PUBLISHING
1. In index.html, replace hello@example.com with your real professional email in:
   - the mailto link
   - the data-email attribute
   - the visible contact hint if you want to keep it
2. Add your real social profile links and real client projects/results.
3. The work section is explicitly marked as illustrative concept work. Replace it with real projects when available.
4. You can publish the folder on GitHub Pages, Netlify, or any static web host.

This site uses Google Fonts from fonts.googleapis.com; a system fallback is included if those fonts cannot load.
